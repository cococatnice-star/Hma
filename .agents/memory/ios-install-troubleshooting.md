The user reported that the shared certificate worked after affected users restarted their phones.

**Why:** The user confirmed this after earlier reports that iOS could not verify the installed app's integrity.

**How to apply:** A phone restart is a reasonable troubleshooting suggestion for a temporary verification failure. This report does not establish that restarting fixes expired or revoked certificates, or that the certificate works on every device or iOS version.
